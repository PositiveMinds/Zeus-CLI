Found it — offset is computed as page * limit instead of (page - 1) * limit, so once you pass the third page it skips past the end of a small result set and the count query throws. Here's the fix:
src/api/users/handler.ts@@ -18,7 +18,7 @@
const limit = Number(query.limit) || 20;
- const offset = page * limit;
+ const offset = (page - 1) * limit;
const rows = await db.users.findMany({ take: limit, skip: offset });
